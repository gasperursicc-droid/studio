# Studio Nua - spletna stran

Statična stran (HTML, CSS, JS), brez gradnje.

## Objava na GitHub Pages
1. Vsebino te mape naloži v koren repozitorija.
2. Settings -> Pages -> Source: "Deploy from a branch", veja `main`, mapa `/ (root)`.

## Kontaktni obrazec
Obrazec na `kontakt.html` pošilja prek storitve FormSubmit na info@studionua.si.
Ob prvem poslanem sporočilu FormSubmit pošlje na ta naslov aktivacijsko povezavo; obrazec deluje šele po potrditvi.

## Slike
Večina slik v `images/` je izrezanih iz posnetkov zaslona (nizka ločljivost). Zamenjaj jih z izvirniki pod istimi imeni.
